# Your photo wall

The template contains no personal photographs. An empty manifest renders
placeholder frames; adding photographs is optional.

To add your own photographs, put them in this directory and edit `manifest.json`:

```json
{
  "photos": [
    { "src": "memory-01.jpg", "caption": "Your own caption" }
  ]
}
```

Use images you have permission to share. For a private gift, keep this directory
and any personalized letters out of a public repository. `.gitignore` ignores
image files in this folder by default; captions and letter text still need review.
